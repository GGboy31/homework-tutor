# Markdown 与数学公式

用于生成或修改作业 Markdown 文件。以下约定已自包含，无须访问语法教程。数学排版属于阅读器扩展，优先遵循学生指定的渲染器；未知时默认使用支持 LaTeX 数学的 Markdown 阅读器约定。

## 块与空白

- 标题的 `#` 后留一个空格；标题、段落、列表、表格和代码块之间留空行。
- 使用 `$...$` 行内公式，定界符内侧不放多余空格，不跨行。
- 块公式的开头和结尾 `$$` 分别独占一行；整个公式块与前后正文各隔一行。不要写成正文末尾紧接 `$$`，也不要把结束标记和下一段写在同一行。
- 顶层公式不缩进四个空格，也不加反引号，避免变成代码块。需要列表内公式时按列表层级正确缩进；不确定时拆成独立段落或小标题。
- 不用行尾空格代替段落空行。这里要求的主要是块外空行与定界符独占行，不是随意往公式里加空格。

## 数学内容

- 多行推导在一个公式块中使用 `aligned` 等受支持环境；检查 `\begin`、`\end`、括号和定界符成对。
- 多字符下标用花括号，例如 `I_{DQ}`；单位用 `\mathrm{}` 或 `\text{}`，例如 `2.5\,\mathrm{mA}`。
- 普通公式不放代码围栏或反引号。仅讲解 Markdown 源码时才用代码块。
- 表格中尽量不放长公式或多行推导；竖线可能干扰表格，优先把复杂公式移到表格外。
- 不为追求兼容性擅自把所有公式降级为代码文本；确知阅读器不支持数学时说明限制并采用学生需要的形式。

## 示例源码

```markdown
## 第 1 题

由课件中的电导率公式可得：

$$
\sigma = q(n\mu_n + p\mu_p)
$$

其中，$n$ 和 $p$ 分别表示电子与空穴浓度。

在满足多数载流子近似的条件下：

$$
\begin{aligned}
\sigma &\approx qN_D\mu_n \\
       &= 0.104\,\mathrm{S/cm}
\end{aligned}
$$

上述数值仅作格式示例；实际参数须由当前题目和课程资料确定。
```

## 交付检查

检查公式块前后空行、独占行的 `$$`、成对定界符与数学环境、列表缩进、标题空格、表格分隔行和有效链接。存在预览工具时查看渲染；没有时报告只完成源码检查，不声称已在目标阅读器验证。
